## PNG Export Instructions (for Claude Code — TC-014 Step 3B)

Use `vp-flow-icon-boxed.svg` as the source for all PNG exports.

Required outputs (write to `public/`):
- `favicon-16.png` — 16×16
- `favicon-32.png` — 32×32
- `icon-192.png` — 192×192
- `icon-512.png` — 512×512
- `icon-512-maskable.png` — 512×512 (same as icon-512, content is already centered within safe zone)

Recommended conversion: `sharp` (Node.js) or `rsvg-convert` (Linux).
