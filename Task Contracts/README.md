# VP-Flow — Task Contracts

All Task Contracts (TCs) for Claude Code execution live here.

---

## Rules

- Every TC must be approved by Delroy before Claude Code may execute it
- TCs are generated by Claude.ai (Cowork) — not by Claude Code
- Claude Code may only read TCs, not modify them (except updating Status after execution)
- No TC = No execution. No exceptions.

---

## TC Naming Convention

TC-[NNN]-[Module]-[Short-Description].md

Examples:
- TC-001-GlobalSearch-RouteFixGuestsToClients.md
- TC-002-PushNotifications-CompleteV2Phase1A.md
- TC-003-Security-HardcodedURLMigrationFix.md

---

## TC Status Values

| Status | Meaning |
|---|---|
| DRAFT | Generated by Cowork — not yet reviewed |
| APPROVED | Delroy has said "Goedgekeurd" — Claude Code may execute |
| IN PROGRESS | Claude Code is currently executing |
| EXECUTED | Implementation complete — restore point created |
| CLOSED | Verified and closed by Delroy |
| CANCELLED | Withdrawn — do not execute |

---

```
[Explicitly what must NOT be done. List every exclusion.]

- [ ] Restore point created after execution

## Notes

[Any additional context Claude Code needs]
```
